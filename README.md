# FigaroProtocol — historical pointer

This repository is the original home of **Figaro v1** (2022) and is maintained at
this address as a stable reference — this URL is cited in the project's USPTO
trademark record (see the current repository's `TRADEMARK.md`).

- **The historical v1 code** now lives, archived read-only, at
  [figaro-protocol/figaro-v1](https://github.com/figaro-protocol/figaro-v1)
  (Genovese 2022; Genovese & Daliana 2023 — the superseded Proof-of-Delivery
  formulation).
- **The current protocol** lives at
  [figaro-protocol/Figaro](https://github.com/figaro-protocol/Figaro) —
  a coordination protocol for self-enforcing agreements between strangers.
  *My word is my bond.*
